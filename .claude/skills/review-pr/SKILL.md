# PRレビュー（プロジェクト固有オーバーライド）

このプロジェクトは個人プロジェクトのため、業務用 Slack への通知はスキップする。

## Slack通知

**セクション5-5「Slackにサマリーを投稿」は実行しない。**

理由: 環境変数 `SLACK_REVIEW_CHANNEL` に業務チャンネル（例: `dev_panasonic_review_android`）が設定されている前提のため、個人プロジェクトの PR レビュー通知が業務チャンネルに流れることを防ぐ。

インラインコメント（Files changed）とサマリーコメント（Conversation）の投稿は通常どおり行う。
